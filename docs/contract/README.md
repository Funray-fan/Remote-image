# 冻结契约

本目录保存团队开发前冻结的协作契约、JSON Schema 和 fixture 说明。

- Word/PDF 阅读版用于分工、评审和归档；
- `schemas/v1/` 是机器可读字段、枚举和必填规则的唯一来源；
- `tests/fixtures/contracts/` 是隔离的合成测试数据，不代表真实模型精度；
- 阶段二真实训练结果在模型验收时提交，不用于反向修改已冻结接口。
